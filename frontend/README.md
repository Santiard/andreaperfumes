# Andrea Perfumes — Frontend (En espera de Mockups)

Esta carpeta alojará la aplicación en **React + Vite**.
Cuando se ejecute `npm run build`, los archivos generados en `frontend/dist/` serán servidos automáticamente por **Nginx** y el motor **SEO / Open Graph** de PHP ([`SeoService.php`](../backend/src/Services/SeoService.php)) inyectará las etiquetas dinámicas en `frontend/dist/index.html`.
